# 只读任务执行效率 v2

本轮针对小任务过度委派、父子重复阅读、长报告交接不完整和读取覆盖误报进行优化。策略适用于新建的 `readonly + answer`，不把普通回答强制改为 JSON；`-analysis` 仍是独立的严格引用报告开关。读取完整、引用可用、结论成立、运行验收分别表示。

## 使用与策略

```bash
go run ./cmd/build-claw -o claw

# 新建只读回答默认自动准入；15份、87105字节的Markdown材料由根Agent执行
./claw -dir /绝对路径/项目 -mode readonly -prompt '读取并分析当前项目文件夹中的md文档'

# 显式关闭委派
./claw -dir /绝对路径/项目 -mode readonly -delegation off -prompt '分析文档'

# 显式开启仍受两个子任务、局部及共享预算限制
./claw -dir /绝对路径/项目 -mode readonly -delegation on -prompt '分别核对两个独立问题'

# 严格引用报告可与委派设置组合；不是所有效率优化的前提
./claw -dir /绝对路径/项目 -mode readonly -analysis -delegation auto -prompt '分析文档'
```

CLI 默认 `workspace`，使用本节只读策略须指定 `-mode readonly`。委派选项为 `auto / off / on`，CLI、飞书群绑定的 `delegation` 及 Bench 用例使用同一含义。新建只读回答默认 `auto`：完整发现范围不超过32个文件且不超过128 KiB时不开子任务；未知、截断或不可读范围也不自动委派。大任务最多两个子任务，要求明确、互不重叠的未读文件范围和预期交付。

每个子任务最多4次模型调用、8次工具尝试，同时扣除共享预算。`on` 只放宽规模判断，不放宽权限、数量或预算。局部额度耗尽只停止当前子任务，并交付已有材料与缺口；不额外调用模型补报告。所有工具尝试，包括拒绝，都计工具预算。

修改任务维持既有行为。恢复沿用原任务策略和已记录计数；旧记录缺少准入计数时显示历史未知，不补造计数，也不自动开启新委派。

## 文件发现、按行读取与复核

`find_files` 返回结构化清单、文件大小、截断及不可读信息，规模来自当前权限内遍历已经取得的信息；发现不代表内容已经读取。后续目录变化不由这次清单持续证明。

按行定位优先使用独立工具：

```json
{"path":"docs/rules.md","start_line":12,"end_line":24}
```

以上为 `read_lines` 参数，默认编号。字节分页使用 `read_file`：

```json
{"path":"docs/rules.md","offset":0,"limit":8000,"line_numbers":true}
```

`read_file` 的旧合法行参数调用继续兼容，但不在新模型 Schema 中混合展示两套定位。混合参数明确拒绝并提供正确示例。两种工具共享路径权限、UTF-8边界、8 KiB上限、版本与实际字节范围，并返回续读位置和EOF。首次阅读启用编号，避免只为补行号全文再读。

同一Agent、同版本、相同请求或已知相同范围，且原文或有效笔记仍可复用时，无目标复读返回 `REJECTED/NONE/duplicate_read`。需要复核时使用：

```json
{
  "path":"docs/rules.md",
  "start_line":12,
  "end_line":24,
  "review":{"target_id":"已有动作、证据或发现ID","question":"核对该默认值是否只适用于V2"}
}
```

引擎验证目标归属及当前版本；必要复核允许执行。父任务首次核对子报告原文不会按全局覆盖一刀切拒绝。重叠但不同范围的读取正常执行，反馈新增、重叠与缺口。文件变化撤销复用资格，恢复不把旧读取提升为本次依据。拒绝不返回旧正文冒充新执行，也不提供透明工具缓存。

## 覆盖与交接

`ReadingCoverage` 由实际读取字节区间计算。每文件完整要求同版本覆盖 `[0,total_bytes)`；空文件也需要成功读取回执。清单未知或发现不完整时不能宣称全目录完整。第五节质量评分文档只读到13685字节、总长14038字节时，应明确缺少 `[13685,14038)`，不能因模型自述“读到400行结束”算完整。

新子报告在原有结束响应内直接产生结构化发现，每条含短结论、版本背景、限制、引用及范围要求；不让模型再写第二份长篇报告。涉及“整个文件没有、全部范围均完成”的判断必须声明 `file` 或 `manifest` 范围要求，覆盖不足时只能列待核实。普通引用只核对读取位置，`-analysis` 保持精确原文字节校验，两者都不证明推理已经验收。

完整报告存入现有不可变材料，`spawn_subagent` 返回不超过8 KiB的完整JSON。超限按完整条目省略并明确数量，不截断JSON前缀。父任务使用：

```json
{"report_id":"报告ID"}
```

```json
{"report_id":"报告ID","finding_ids":["F1","F3"]}
```

以上为 `read_report`。目录过长时按返回的 `next_after_id` 使用 `after_id` 续读目录；不是字节分页。单项详情仍超过限额时返回完整材料入口，不输出半份JSON。旧 `read_evidence` 保持字节分页兼容。

报告分别显示执行、引用、读取覆盖及运行验收。没有运行Python或没有看截图属于限制，不抹掉有效阅读依据。文件变化按发现撤销，避免一条引用过期删除整份报告。读取接口核对父任务、运行及路径权限；历史报告不自动成为当前有效证据。

CLI与飞书在统一终报展示覆盖，观测台交付页展示清单、逐文件缺口和历史/未知状态；详情页显示普通回答或严格分析、实际委派设置。跨运行边界清除旧覆盖，所有内容使用文本节点渲染。

## 验证与结果边界

```bash
go test ./cmd/... ./internal/...
go test -race ./internal/...
go build ./cmd/... ./internal/...
python3 scripts/real_eval/run.py selfcheck
```

离线验证包含会改变执行轨迹的委派准入、局部预算、重复读取、长报告尾部发现、缺页覆盖、版本变化、权限、恢复及存储失败。保留原固定8模型/30工具回放，但其材料字节下降不能证明真实整任务降耗。

真实对照冻结实施前baseline和candidate，使用相同模型、网关、题面、文档、新会话和独立工作区。先运行一对；候选质量通过、完整交付且不超过12模型/40工具后，最多扩到三对六样本。两组上限一致：60模型、120工具、30轮、600秒、300000字节；全批最多360次模型准入，基础设施失败不自动重试。失败样本保留消耗，未知Token或费用为 `null`。

本任务待验证目标为候选中位数不超过12模型/40工具，总输入输出Token中位数较同批基线减少至少30%；人工质量至少8/10、不低于基线且零重大事实错误。真实结果由该批证据归档单独记录；未通过时不能宣布整任务降耗完成，也不把小样本结果泛化到所有任务。

新字段兼容旧记录，历史缺失显示未知；不自动删除任务、材料或观测数据。手动清理前确认相关进程已退出，并整体备份任务及其材料。

## 本轮真实首对结果

本轮使用冻结的实施前二进制与候选二进制、同一份15文档（87,105字节）、普通只读回答、新会话和相同预算进行自由轨迹对照。没有开启 `-analysis`，候选的任务状态和观测事件均确认 `delegation=auto`。

| 指标 | 基线首个样本 | 候选首个样本 |
|---|---:|---:|
| 模型调用 | 30 | 12 |
| 工具尝试 | 66 | 52 |
| 输入 Token | 404,037 | 310,131 |
| 输出 Token | 52,274 | 17,647 |
| 总 Token | 456,311 | 327,778 |
| 耗时 | 285.15 秒 | 127.84 秒 |

总 Token 降低 **28.17%**，模型调用减少60%；但工具52次超过40次门槛，Token降幅也不足30%。运行器已拒绝扩样，仅完成首对2个样本、共42次模型准入，没有继续第二、第三对，未将目标标为通过。两组均 ANSWERED、完整覆盖15文档、无越界文件变更、无未决动作或Provider错误；费用未知，保持null。

质量记录由本次代码助手对照冻结原文核对，非真人评审、未额外请求被测Provider进行评审。候选提供更具体的文件/行号引用，主要静态判断有来源；两组仍有版本或实验背景限定不足。记录分数仅作为本次工程检查，不是独立语义准确率证明。

剩余瓶颈：候选成功读取47次，其中27次未增加同文件同版本的字节覆盖，累计读取194,939字节；基线成功读取23次、3次零新增。新候选没有子任务，但普通模式的20条历史窗口仍会淘汰早期正文；材料已不再可复用时，安全复核规则会允许再次读取。另外，不同区间的重叠请求按本轮策略允许执行；零新增字节不等于每次核对都没有价值。不能声称复读问题已解决。后续需要研究根任务有来源的事实记忆与普通答复格式解耦，不能靠无条件禁止复核来达标。

历史固定8模型/30工具回放继续检验原文与笔记保留、配对和去重机制；v2已把Progress去重也用于普通模式，因此新普通与分析模式的材料差异不再代表旧版到新版的总收益。历史35.32%不覆盖本次实际28.17%，真实30%门槛没有修改。

完整证据见 `.claw/evals/efficiency-v2-20261106T065006Z-6e4c4029/` 的 manifest、summary、pilot-report、read-diagnostics、quality-review 及 samples 目录。此结果只限本任务首对，不能泛化为其他任务的稳定收益。
