## 行为与边界

- 新请求默认记录参数清单；明确选择 `on_error` 才保存本地脱敏失败请求及匹配的上一成功请求。开关前后三协议发送字节一致。
- 参数区分未发送、null、实际零值、false 和未知。复杂参数仅保留工具选择、格式和推理级别等白名单摘要，不把 Schema 描述或业务正文塞入观测日志。
- 来源绑定最终实际投影：原文、折叠标记和未知分别表示；并发开始时冻结前次成功身份，按 Agent/渠道/协议/端点/模型隔离。空答复、私密思考和 2xx 解析失败不更新成功缓存，已知用量仍保留。
- 诊断元数据完整不等于正文已保存。限额、队列满、锁忙、目录不可写及关闭超时都有独立缺口，失败保存不冒充完整副本，不改变引擎结果。
- 脱敏夹具覆盖嵌套和顶层错误信封；内容拒绝后的确认文件保留，仍为 `FAILED/model_content_rejected/1`，不会标记成功或自动重试。
- 观测台仅展示摘要和独立 ID，无正文端点。1280px 与 768px 实际浏览器验收通过，无横向溢出或应用脚本异常。
