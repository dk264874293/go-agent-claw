## 完整 HTTP 性能验收

机器环境：macOS（darwin/arm64），Go 1.26.5，18 个逻辑 CPU，GOMAXPROCS=18。合成数据为 1,000 个任务、100,000 条事件、54,792,000 字节（52.25 MiB），初次索引耗时 1.646 秒。接口计时包含认证、出站脱敏、JSON 编码、HTTP 传输及响应正文读取。

| 指标 | 实测 | 样本数 | 目标 |
| --- | --- | --- | --- |
| 原始任务列表第一页 P95 | 5.823 ms | 100 | ≤200 ms |
| 工作区概览 P95 | 3.229 ms | 100 | ≤200 ms |
| 轻量任务列表第一页 P95 | 2.937 ms | 100 | ≤200 ms |
| 异常任务第一页 P95 | 4.440 ms | 100 | ≤200 ms |
| 新增记录至 HTTP 可见 P95 | 1.656 秒 | 10 | ≤2 秒 |

三个新路径分别为 `/api/v1/overview`、`/api/v1/tasks?view=summary&page_size=50`、`/api/v1/alerts?page_size=50`。列表均核对全量任务数和分页条数；概览核对全量任务数及两个限量列表。

增量可见性使用正式服务相同的一秒索引刷新与 20 ms HTTP 查询轮询，从完整日志发布后开始计时。该指标只证明接口可见性，不代表浏览器完成 DOM 更新的时间。

## 浏览器与前端验证

使用本机真实 Chrome（Playwright 驱动），读取已有 30 个 v2 评测样本与隔离离线夹具；未新增模型或 oracle 调用。浏览器脚本、截图和原始结果保存在项目本地 `.claw/monitor-validation/ui-v2/`，不纳入 Git。

已验证：

- 总览四卡与限量列表显示正常，等待审批计入运行活动子集；凭据兑换后地址栏没有 token fragment。
- 总览、任务、异常、评测及详情五个标签在 1440、1280、768、390px 下均无页面横向溢出；评测表格在自身容器内横向滚动。检查浅色及跟随系统的深色外观。
- 时间线首批加载 200 条；继续加载后保留全部后续事件。关键事件模式折叠普通心跳，记录缺口持续可见，显示全部后能够展开原始事件。
- 通过事件序号保存 `event=210` 链接；刷新后恢复任务、尝试、时间线标签和目标事件，自动加载目标所在的后续页。
- 阅读第 210 条事件期间，通过隔离日志真实追加一条记录并等待 SSE 更新。原事件 DOM 节点、展开状态、键盘焦点和 10 字符选区全部保留；阅读锚点在视口中的偏移为 **0.1875px**。页面文档滚动量随上方新增提示变化 91px，锚点仍保持原位置。
- 新增事件只显示查看入口；主动点击后再定位。完整浏览器验收没有应用脚本错误。

另测 10 次日志发布至总览任务标题 DOM 可见延迟，不主动刷新页面：P95 为 **1.298 秒**，最大 1.298 秒。该测量使用正式服务一秒刷新、SSE 和真实浏览器，计时从隔离日志原子发布前开始；它覆盖当前正常浏览器负载，不替代上一节 1000 任务数据集的 HTTP 性能结论。原始样本见 `dom-latency.json`，阅读稳定性见 `browser-results.json`。

## 接口与兼容边界

`/api/v1/tasks` 默认完整返回及现有参数保持兼容，轻量返回通过 `view=summary` 显式选择。新增 `/overview`、`/alerts` 与评测工作区筛选均只查询已有投影，不执行或恢复任务、不读取任意客户端路径、不调用模型。活动未知、引擎持久结果、文件回执和独立验收继续分别展示。

接口参数、状态计数口径、分页限制和启动方式见 [使用与实现说明](local-monitor.md)。
