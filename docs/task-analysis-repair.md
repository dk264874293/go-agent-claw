## 报告与证据

子任务优先输出包含字符串 `findings`、引用数组 `evidence` 和未核实项数组 `unverified` 的 JSON 对象。既有对象或数组形式的 `findings` 确定性编码为 JSON 文本，不为格式修复增加模型请求。引用仍须满足实际读取范围、路径权限和文件版本检查；报告状态由引擎计算。格式可处理、引用有读取依据，均不表示结论已通过语义验收。

无效 JSON、本地轮次耗尽等情况保留原始报告、公开输出片段、读取回执和停止原因，不能将原始分析文字标成成功报告。失败材料不复制完整模型请求、工具正文及 Responses 私密项。

`read_evidence` 的 `offset` 为非负源字节偏移，`limit` 默认为 4000，范围为 1 至 4000；兼容旧调用显式传入 0 使用默认值。下一页使用结果中的“下一段 offset”，不能按显示字符数推算。UTF-8 文本按完整字符切页，字符中间的偏移会收到纠正提示；末尾读取为空页。返回的总长度、EOF 和区间均针对源材料。

## 读取复用

文件读取同时产生可选结构化回执，包含路径、版本、源字节区间、行区间及总长度。原文本元数据头继续保留；新回执由读取实现提供，不从输出正文猜测。回执随动作结果保存并关联 Agent 和动作身份。

同一运行的覆盖目录合并同路径、同版本的区间，模型上下文最多注入最近 128 条、合计 16 KiB。父 Agent 可以接收经过结构及引用检查的子报告，新子任务只获得权限范围内的覆盖目录，不获得兄弟子任务的自由文本摘要。复用前复核文件版本，文件写入使对应路径失效，实际 Bash 执行清空当前目录。恢复后的新运行重新建立内存目录，旧回执只说明历史读取。

覆盖范围不代表全部内容已经理解，也不禁止必要的重新读取。工具调用仍按原准入和预算执行。

## 部分分析与预算收尾

根 Agent 工具额度用尽时，先等待当前并发批次结束、配齐调用结果，然后按剩余额度决定是否收尾。收尾额外占用一轮和一次模型调用，使用相同的上下文上限与总时间上限，禁止工具、额外思考、规划、委派和验收。没有足够额度或已取消时不增加请求。

收尾准入及扣额在同一个持久事件中完成。同一工具额度边界只准入一次；恢复遇到已开始但结果未确认的记录，不重复调用。提高工具上限后可继续探索，耗尽新边界时可以有新的一次收尾机会。

收尾空文、工具调用或请求失败均不执行工具、不重试，改用记录摘要。`RunResult.partial_report` 为可选字段，包含 `text`、`source`（`model` 或 `recorded`）和 `origin_run_id`，与 `final_text`、`delivery` 各自独立。预算收尾不改变预算失败终态、停止原因和退出码，不标记计划完成或验收通过。存储错误及取消仍遵循原有规则。

统一终报在 `Run` 返回后发布一次。观测台在交付页单独展示部分分析、来源运行和停止原因；历史来源明确提示当前文件状态仍需核实。新运行的开始记录和入口结果身份不一致时，不将旧部分分析展示为本次交付。任务文本使用不可信文本方式渲染。
