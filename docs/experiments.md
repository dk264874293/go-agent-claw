## 阅读时分开六层证据

1. **已实现**：源码有入口与状态，并不保证真实模型采用。
2. **确定性回归通过**：给定脚本意图、工具和故障下，程序保持预期不变量。
3. **模型实际采纳**：真实调用轨迹使用了能力；开放工具 Schema 不等于采用。
4. **交付成功**：有合法产物和回执；不代表内容正确。
5. **语义质量通过**：在明确量表、来源和评审协议下达到标准；评审者与独立性需注明。
6. **同等质量下成本改善**：只有质量与比较协议有效时才成立；原始 Token 下降单独保留。

`null` 表示未知或未获得数据，`not_run` 表示未执行，不补成0或通过。检查点与构建摘要用于绑定历史输入，不以当前源码替换当时实验版本。新增回放或修复读取器不会追认旧实验成功。运行方法见[开发与测试](development.md)，完整历史索引仍保留在[文档导航](README.md)。
