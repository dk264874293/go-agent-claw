## 文件发现、目录类型与文本边界

- `find_files` 用于寻找文件名，`search_text` 用于搜索正文。查找 Markdown 时使用 `find_files({"path":".","name_glob":"*.md","limit":200})`，不能用正文查询 `*.md` 代替文件名匹配。
- 文件名模式按 basename 匹配，递归遍历登记范围；不使用 `**`，不提供分页 offset。清单有界，截断时应缩小路径范围，不能把节选当作全部文件。
- 名称以 `.md` 结尾的目录仍是目录，不能出现在 Markdown 普通文件清单中。符号链接、范围和受保护运行目录继续遵守原工具边界。
- `list_dir` 仅接受目录。对普通文件的误用返回稳定错误码、不可重试标记及中文纠错信息，不作为暂时性磁盘或网络错误反复尝试。
- `search_text` 在文件级排除图片、PDF、可执行文件等二进制正文。不能只逐行跳过 NUL 后继续返回其余二进制行。未搜索、被跳过及截断的材料不能被描述为没有匹配项的完整证据。

工具调用预算仍按尝试计数；文件发现、纠错和重复检测不扩大读取权限，也不自动提高预算。

## 只读失败后的部分分析

类型化的 `readonly_repeat` 与普通 `BLOCKED` 分开。只有明确属于局部只读探索、效果已知且记录可靠的重复失败，才进入根 Agent 的一次禁工具部分汇总。权限、审批、路径越界、未知效果、写入或 Bash 失败、存储故障和协议错误不因本规则获得额外模型调用。

收尾使用原有剩余模型、轮次和时间额度，额外占用一轮和一次模型调用。准入标记先持久化；同一失败边界已开始、完成或失败后，恢复不重新请求。收尾期间不规划、不委派、不验收，不执行模型附带工具调用。空答复或请求失败改用已记录事实摘要。

引擎保留 `BLOCKED/readonly_repeat`、退出码 2、空 `FinalText`；部分分析单独放在 `PartialReport`，不标记任务完成或验收通过。取消与关键存储失败仍具有原有优先级。既有 `BudgetClosing` 及预算耗尽结果保持兼容。
